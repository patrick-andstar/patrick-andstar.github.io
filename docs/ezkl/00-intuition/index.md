# 直觉入门

这一层不碰任何数学，只建立「证明」这件事的直觉：谁在证什么、给谁看、为什么可以只验一次。

学完这一层，你应该能做到：**用自己的话讲清 EZKL 到底在证什么、没证什么。**

| 级别 | 知识点 | 一句话 |
|---|---|---|
| 核心 | [陈述与见证](statement-witness.md) | 把「我要证明什么」拆成两半：statement 是公开的那句话，witness 是只有你知道的那份数据。 |
| 核心 | [零知识的三种动机](why-zero-knowledge.md) | ZK 有三种用途：藏数据（隐私）、压缩验证（简洁）、证明别人算对了（可验证计算）。EZKL 是第三种。 |
| 核心 | [交互式证明的直觉](interactive-proof.md) | 验证者反复随机提问，证明者每次都能答对，则他大概率真的知道。骗一次的概率 1/2，骗 k 次是 1/2^k。 |
| 核心 | [从交互到非交互](fiat-shamir.md) | 把验证者的随机挑战换成「对已有全部消息取哈希」，验证者不在场也能验，一次通信完成。 |
| 核心 | [EZKL七步流水线](ezkl-pipeline.md) | table → gen-settings → compile → setup → gen-witness → prove → verify，七个命令、七种产物。 |
