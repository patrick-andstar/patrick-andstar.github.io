# 术语白话对照表

看卡片时卡在某个词上，先来这里查。每条只给「够用」的解释，完整定义等你看懂整体之后再补。

| 术语 | 白话解释 | 出现在 |
|---|---|---|
| 有限域（素域） | 只保留余数的算术，但加、减、乘、除都能做（除 0 以外）。计算机里所有密码学数字都住在这里。 | 01 |
| Fr / Fq | 同一个曲线上的两套数字系统：Fr 存「数量」（见证、标量），Fq 存「坐标」。不能混。 | 01 |
| 椭圆曲线 | 形如 y² = x³ + ax + b 的一堆点，点与点能「相加」。名字里的「圆锥曲线」是它所属的大类。 | 01 |
| 生成元 / 阶 | 循环群里一个「种子点」，反复自加能走遍所有点；走一圈回到原点的次数叫阶。 | 01 |
| 标量乘法 | k·P = P 自加 k 次。正向好算，反推 k 叫离散对数问题，极难。 | 01 |
| 配对（pairing） | 一种「隔空验算」运算：不打开箱子也能验里面两个数相乘对不对。KZG 的验证就一行配对。 | 01 |
| 承诺 | 先把东西封存公布（隐藏），以后只能按原样打开（绑定）。 | 02 |
| SRS | 一套公共参数文件，本质是 [τ, τ², τ³…] 被「盖章」后的结果。它是 KZG 的模具。 | 02 |
| τ（tau）/ 有毒废料 | 造 SRS 时用的那个秘密数。谁留着它，谁就能伪造证明。留着的那份叫有毒废料。 | 02 |
| 打开（opening） | 证明「这个多项式在 x 点的值确实是 v」，但不交出整个多项式。 | 02 |
| transcript | 「到目前为止双方说过的所有话」的流水账。挑战值就是从这本账里算出来的。 | 02 |
| Fiat-Shamir | 把「验证者现场出题」换成「对流水账取哈希当题目」，于是不用来回通信。 | 02 |
| 算术化 | 把「算一遍」翻译成「一堆必须成立的等式」。这是 zk 里最费脑的一步。 | 03 |
| 电路 / 门 / 线 | 电路不是电子电路，是一堆约束的集合；门=一条约束，线=被约束的变量。 | 03 |
| witness（见证） | 给每个变量填的具体数值。你知道，验证者不知道。 | 03 |
| instance（公开输入） | 写进证明、验证者能直接看见的那部分值。 | 03 |
| advice / fixed / instance 列 | 表格的三类列：自己填的草稿 / 印死的常量 / 交给对方看的答案。 | 03 |
| 选择子（selector） | 一排 0/1 开关，决定这一行执行哪种运算。 | 03 |
| 复制约束 / 置换论证 | 证明「这些格子里的值彼此相等」的省事办法：不写 N 条等式，而是证明它们能重排成一模一样。 | 03 |
| grand product | 置换论证里那个「连乘」，用一个乘积就把所有相等关系打包。 | 03 |
| 自定义门 | 把常用小运算（如曲线加法）做成专用模具，一次压多行，省行数。 | 03 |
| 商多项式（quotient） | 把所有约束加起来除以「整域为零」的那个固定多项式，除得尽就说明每条约束都成立。 | 03 |
| 查找表 / lookup | 不会算就查表。表是预先算好的，电路只证明「我真查了，没瞎编」。 | 03 |
| Plookup / LogUp | 两种「证明查过表」的经典做法。LogUp 更省，EZKL 用的分支走这条线。 | 03 |
| MVLookup | 「一次查多列」的查找，表还能是现场写的（动态表）。EZKL 的非线性算子靠它。 | 03 |
| range check | 规定每个格子只能写 b 位以内的数。不规定，溢出就查不出来。 | 03 / 05 |
| chip / region | halo2 里的代码组织单位：chip 是一组能复用的电路零件，region 是它在表格里占的那块地。 | 03 |
| 完备性 / 可靠性 / 零知识 | 真话一定过 / 假话几乎过不了 / 过了也看不出秘密。 | 04 |
| 可靠性误差 | 「假话蒙混过关」的概率上限。一般要求小到 2^-100 以下。 | 04 |
| 抽取器 / 模拟器 | 证明可靠性用的工具（能从证明里掏出 witness）/ 证明零知识用的工具（不看秘密也能伪造出一样的对话）。 | 04 |
| 递归 / 聚合证明 | 把 N 个证明再「证一遍」，合成一个。v23 已删，属于缺口。 | 04 |
| pk / vk | 证明密钥（大，只有证明方用）/ 验证密钥（小，谁都能拿）。 | 04 |
| logrows（k） | 电路行数取 log2，k=16 就是 65536 行。k 每加 1，行数、SRS、内存全翻倍。 | 04 / 06 |
| 定点量化 | 用整数存小数：真实值 = 整数 × 2^-s。s 就是 scale。 | 05 |
| 溢出 | 数超出可表示范围，绕回去了。账面每步都对，结果却错——ZK 查不出来。 | 05 |
| einsum | 「张量收缩」的通用写法，卷积、矩阵乘都能写成它。 | 05 |
| lowering | 把高层算子（卷积）翻译成低层零件（乘加、查表）的过程。 | 05 |
| ONNX | 一份跟框架无关的「算子清单 + 权重」文件，EZKL 只认它。 | 05 / 07 |
| zkML | 用零知识证明来证「模型推理算对了」的整套做法，EZKL 是其中一个实现。 | 05 |
| MSM | multi-scalar multiplication，一次算几千个「标量×点」再求和。证明里最耗时的那一步。 | 06 |
| NTT | 有限域上的快速傅里叶变换，把「逐个代入」变成「分批一起算」。 | 01 |
| Poseidon | 专为电路设计的哈希，比 SHA256 省几十倍约束，代价是安全性论证更新。 | 02 |
