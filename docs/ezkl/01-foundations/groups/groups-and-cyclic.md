## 一、为什么突然讲「群」

你天天在做加法，但有没有想过：**「加法」到底是什么？**

数学家发现，很多看起来完全不同的操作，其实遵守同一套规矩：整数相加、钟表转圈、曲线上的点相加、置换的复合……于是他们把这套规矩抽出来，叫**群（group）**。

学它的唯一理由：后面所有承诺、所有证明，**99% 的运算是在一个群里做「加法」和「乘一个整数」**。你不认识群，就看不懂 SRS 为什么长那样。

## 二、群的四条规矩

一个集合 G，配一种运算（记作 +），满足下面四条，就叫群：

| 规矩 | 意思 | 反例 |
|---|---|---|
| **封闭** | 任意两个元素运算完还在集合里 | 奇数 + 奇数 = 偶数，不在奇数集合里 → 不封闭 |
| **结合律** | (a+b)+c = a+(b+c) | 减法不满足 |
| **单位元** | 有个 0，使 a+0 = a | — |
| **逆元** | 每个 a 都有 −a，使 a+(−a) = 0 | 正整数加法没有负数 → 不是群 |

如果还满足 **a+b = b+a**（交换律），就叫**阿贝尔群**。我们要用的都是阿贝尔群。

## 三、循环群：一个种子能走遍全场

如果群里存在一个元素 G，使得**反复用 G 自己加自己**，能把所有元素都走出来，这个群就叫**循环群**，G 叫**生成元**。

看两个例子（都在 mod 7 下）：

**加法群**：G = 1
1, 2, 3, 4, 5, 6, 0 ← 走遍了全部 7 个元素。所以 1 是生成元，群的阶是 7。

**乘法群**（只取非零元素）：G = 3
3¹=3, 3²=9≡2, 3³=6, 3⁴=18≡4, 3⁵=12≡5, 3⁶=15≡1 ← 也走遍了全部 6 个元素。阶是 6。

注意第二行：**乘法群里的「自加」变成了「自乘」**，写法不同，结构一样。以后看到 k·G 和 G^k，先判断是哪种运算。

## 四、落到 EZKL 上

EZKL 用的 G1 就是一个**阶为 r 的循环群**（r ≈ 2²⁵⁴）。

- 生成元 G 是固定的一个点；
- SRS 里放的是一串 `τ⁰·G, τ¹·G, τ²·G, …`（`02/02/04`）；
- 因为 **r·G = 无穷远点**，所以「第几个」这个编号天然只在 0..r−1 里有意义 —— 这就是上一篇说的「标量模 r」。

**为什么这件事值得单独学**：所有承诺都是群元素，证明里最耗时的操作（MSM）本质就是「几千个标量乘 + 点加」。你不懂群，就看不懂为什么 `pk.key` 有 265 MB，也看不懂为什么 GPU 加速只对某一步有效。

## 五、一个必须纠正的直觉

**群里的「加法」不是坐标相加。**

两个曲线点 P=(x₁,y₁)、Q=(x₂,y₂)，P+Q 的结果**不是** (x₁+x₂, y₁+y₂)。它有自己的一套几何/代数规则（下一篇讲）。

同理，「2G」不是把坐标乘 2，而是 G+G。

这个坑很常见：看到 `a·G + b·H` 就以为在算坐标的线性组合。不是，是点加。

## 六、自检答案

> 问：G1 的阶 r、生成元 G、以及「r·G = 无穷远点」这三者是什么关系？

答：G 是 G1 这个循环群的生成元，反复加它能走遍群里全部 r 个元素（加上无穷远点共 r 个）。走满 r 次就回到单位元，即 r·G = O。所以「第 k 个元素」这个 k 只在 0..r−1 内有意义，标量因此天然模 r。

## 七、一句话记住

**群 = 一套能做加减、有零、有相反数的运算。循环群 = 一个种子能走遍全场。**
