# 机器学习预备

这一层只补 EZKL 真正会用到的机器学习常识：模型长什么样、算子怎么算、推理和训练差在哪。不讲训练技巧、不讲调参、不追论文。哪一条看不懂就回头补，看懂就跳过。

学完这一层，你应该能做到：**拿到一个 ONNX 模型，能说出它的输入输出形状、有哪几类算子、哪些算子会在电路里变贵。**

| 级别 | 知识点 | 一句话 |
|---|---|---|
| 支撑 | [神经网络就是矩阵乘加](neural-net-as-matmul.md) | 一层网络 = 一堆乘法加法，再套一个非线性函数。所谓「深度」，就是把这件事重复几十次。 |
| 核心 | [张量与形状](tensors-and-shapes.md) | 张量就是多维数组。形状（shape）决定两个张量能不能相乘，也决定电路要开多少行。 |
| 核心 | [卷积与感受野](convolution-receptive-field.md) | 卷积 = 拿一个小窗口在图上滑动，每滑一次做一次加权求和。权重在所有位置共用，所以参数比全连接少得多。 |
| 核心 | [激活函数](activation-functions.md) | ReLU 是「负数归零」；Sigmoid/Tanh 是把数值压进 0~1 或 −1~1 的 S 形曲线；GELU 是平滑版 ReLU。 |
| 核心 | [归一化与Softmax](normalization-softmax.md) | BatchNorm 按通道统计、LayerNorm 按单个样本统计；Softmax 把一排分数变成加起来等于 1 的概率。 |
| 核心 | [推理与训练的区别](training-vs-inference.md) | 推理只做前向：输入进、结果出。训练还要反向传播算梯度、再用优化器改权重，中间状态多得惊人。 |
| 支撑 | [模型导出与ONNX](export-onnx.md) | PyTorch 训完导成 ONNX：一份「算子清单 + 权重」的通用文件，跟框架无关。EZKL 只认它。 |
| 支撑 | [什么是量化](what-is-quantization.md) | 把 float32 的权重压成 int8/int16 这类整数，省内存、省算力，代价是精度。EZKL 更进一步，用定点整数。 |
| 支撑 | [残差连接与ResNet](residual-resnet.md) | 输出 = 输入 + 变换(输入)。这条「直通线」让很深的网络也能训得动，代价是电路里多一次加法、多一份形状对齐。 |
