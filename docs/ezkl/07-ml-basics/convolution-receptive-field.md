# 卷积与感受野

> **核心** ｜ 前置：07_机器学习预备/02_张量与形状

**一句话**：卷积 = 拿一个小窗口在图上滑动，每滑一次做一次加权求和。权重在所有位置共用，所以参数比全连接少得多。

## 一、卷积在做什么

拿一个 3×3 的小窗口，在图上从左到右、从上到下滑动。每停一次：

1. 取窗口里 9 个数；
2. 乘上 9 个权重；
3. 加起来，得到一个输出值。

滑完一遍，就得到一张新的「特征图」。

**它像用一个放大镜扫过整张图，每处都记录「这里像不像我要找的纹理」。**

## 二、两个关键设计

**设计一：权重共享**

同一个 3×3 的核，在图上所有位置都用同一套权重。

- 好处：参数极少（9 个 vs 全连接的几百万个）；
- 好处二：平移不变（猫在左上角还是右下角，同一个核都能检测到）。

**设计二：多通道**

一个核只能检测一种纹理。所以用 64 个核，就得到 64 张特征图，每张对应一种模式。

这就是「输出通道数 = 卷积核个数」的由来。

## 三、感受野：堆叠让小窗口看懂大图

单个 3×3 卷积，每个输出只看得到输入的 3×3 区域 —— 这叫**感受野 = 3**。

但堆两层：

- 第 2 层的每个点，看的是第 1 层的 3×3；
- 第 1 层的每个点，看的是原图的 3×3；
- 所以第 2 层的每个点，间接看到原图的 **5×5**。

堆三层 → 7×7。规律：

> **n 层 3×3 卷积，感受野 = 2n + 1**

这就是为什么现代网络全用 3×3 堆叠，而不是一个大 7×7：**同样的感受野，参数更少、非线性更多。**

（ResNet50 第一层还留了个 7×7，是为了快速降分辨率，属于工程取舍。）

## 四、stride 和 padding 在干什么

| 参数 | 作用 | 副作用 |
|---|---|---|
| `stride=2` | 每次跳 2 格 | 输出尺寸减半，计算量减 4 倍 |
| `padding=1` | 边缘补一圈零 | 保持尺寸不变 |
| `dilation` | 核中间插空 | 不增参数扩大感受野 |

stride=2 是 CNN 里最重要的「降本」手段：分辨率减半，后续所有层的行数都跟着减 4 倍。

## 五、池化：另一种降分辨率

`MaxPool(2×2)`：每 2×2 取最大值，尺寸减半。

它没有参数，计算也简单。但在电路里它**比想象中贵**（`05/01/02`）：

- 取最大值要逐元素比较；
- 电路里「比较」不是一条指令，要拆位或用查表。

所以现代网络越来越多用 `stride=2` 的卷积替代池化 —— 既降分辨率，又能学参数，而且在电路里成本更可控。

## 六、自检答案

> 问：说清「3×3 卷积 + stride=1 + padding=1 为什么形状不变」。

答：输出尺寸公式是 H_out = ⌊(H + 2p − k)/s⌋ + 1。代入 k=3、p=1、s=1 得 (H + 2 − 3)/1 + 1 = H − 1 + 1 = H，尺寸不变。直觉上，3×3 核的半径是 1，补一圈零正好让边缘像素也能被完整覆盖，所以每个输入位置都对应一个输出位置。

## 七、一句话记住

**卷积 = 滑窗 + 权重共享。堆 n 层 3×3，感受野 2n+1；stride=2 是最便宜的降本手段。**
