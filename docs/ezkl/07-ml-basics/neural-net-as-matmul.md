# 神经网络就是矩阵乘加

> **支撑** ｜ 前置：无

**一句话**：一层网络 = 一堆乘法加法，再套一个非线性函数。所谓「深度」，就是把这件事重复几十次。

**在 EZKL 里的落点**：无（这是 05 层所有「行数估算」的起点）

> 读完约 6 分钟。这一篇把「神经网络」还原成一件事，为后面所有成本估算打底。

## 一、一层在做什么

一个全连接层：

> y = W · x + b

- x 是输入向量（比如 784 维，一张 28×28 的手写数字）；
- W 是权重矩阵（比如 128×784）；
- b 是偏置（128 维）；
- y 是输出（128 维）。

然后套一个激活函数：`h = ReLU(y)`。

**就这些。** 没有别的魔法。

## 二、算一遍参数

W 是 128×784 = 100,352 个参数，b 是 128 个。这一层约 10 万参数。

一次前向要做的乘法：128 × 784 = 100,352 次乘加。

如果网络有 10 层这样的，就是 100 万次乘加、100 万参数。

## 三、为什么电路里也是乘加

因为矩阵乘的本质就是：

> yᵢ = Σⱼ Wᵢⱼ · xⱼ

一堆乘法 + 一堆加法 —— **恰好是电路唯一会做的事**。

所以全连接层在电路里是「最友好」的算子：每一次乘加占一行（或几行并行），没有查表、没有除法、没有分支。

## 四、深度是什么

「深度」= 重复这件事的次数。

```
h₁ = ReLU(W₁x + b₁)
h₂ = ReLU(W₂h₁ + b₂)
…
y  = Wₙhₙ₋₁ + bₙ
```

每一层的输出是下一层的输入。**没有循环、没有记忆、没有递归。**

这也是为什么推理可以被电路完整表达：它是纯前馈的、确定性的。

## 五、卷积只是「参数更少的矩阵乘」

卷积层也是乘加，只是：

- 权重共享（同一个核在空间上滑动）；
- 局部连接（每个输出只看一个小窗口）。

展开之后（`05/01/03`），它就是矩阵乘。

**所以整个 CNN = 一串矩阵乘 + 一些逐元素操作（激活、归一化、池化）。**

## 六、这给成本估算什么启示

记住一条：

> **成本 ≈ 乘加总次数 / 每行并行度**

- 参数量 ≠ 成本（卷积参数少但乘加多）；
- 层数 ≠ 成本（一层大的可能比十层小的贵）；
- 真正的指标是 **MAC（multiply-accumulate）总数**。

ResNet50 约 4.1 G MAC，25.6 M 参数 —— 参数和计算量差 160 倍。

## 七、自检答案

> 问：用矩阵写出 y = Wx + b，并说出 W、x、b 各自的形状。

答：若输入 784 维、输出 128 维，则 x 是 784×1，W 是 128×784，b 是 128×1，y 是 128×1。矩阵乘要求 W 的列数等于 x 的行数（784），结果的行数等于 W 的行数（128）。批量处理时 x 变成 784×B、y 变成 128×B（B 是 batch size）。

## 八、一句话记住

**神经网络 = 一串「矩阵乘 + 加法 + 逐元素函数」。电路喜欢前两个，讨厌第三个。**
