# 张量与形状

## 一、张量就是多维数组

- 一个数：标量（0 维）
- 一排数：向量（1 维）
- 一张表：矩阵（2 维）
- 一叠表：3 维张量
- 再加「通道」「批次」：4 维、5 维

深度学习的张量通常写成 `NCHW` 或 `NHWC`：

| 记号 | 含义 |
|---|---|
| N | batch，一次处理几张图 |
| C | channel，通道数（RGB 就是 3） |
| H / W | 高 / 宽 |

所以 `[1, 3, 224, 224]` 就是「1 张 224×224 的彩色图」。

## 二、形状为什么重要

因为**两个张量能不能相乘，由形状决定**。

矩阵乘要求「内维相等」：

> [1, 3, 224, 224] × [64, 3, 7, 7] → 内维 3 对上了，可以卷

如果内维对不上（比如 3 对 4），程序直接报错。

在电路里，形状还决定一件更贵的事：**要开多少行**。

> 行数 ≈ 输出元素总数 × 每元素乘加数 / 每行并行度

所以形状一变，成本可能成倍变（`05/01/03`）。

## 三、卷积的形状公式（最常用的一条）

> **H_out = ⌊(H_in + 2p − k) / s⌋ + 1**

- k：卷积核大小
- p：padding（边缘补零的圈数）
- s：stride（步长）

算两个常见的：

**例 1**：输入 224，k=7，s=2，p=3
> (224 + 6 − 7)/2 + 1 = 223/2 + 1 = 111.5 → 111 + 1 = **112**

（ResNet 的第一层就是 224 → 112。）

**例 2**：输入 56，k=3，s=1，p=1
> (56 + 2 − 3)/1 + 1 = 55 + 1 = **56**

**形状不变**。这就是为什么「3×3 卷积 + padding=1」被称为「same padding」——它保持尺寸。

## 四、为什么 padding 是 1 而不是别的

因为 k=3 时，卷积核半径是 1（左右各 1 个像素）。补 1 圈零，正好让边缘像素也能被「居中」处理。

规律：**p = (k−1)/2** 时形状不变（k 为奇数）。

k=5 就要 p=2，k=7 就要 p=3。这也是为什么卷积核几乎都是奇数。

## 五、一个实际影响行数的细节

`NCHW` 和 `NHWC` 只是排列不同，数学上等价，但**在电路里成本可能不同**。

因为电路按「列」组织数据，不同排列会导致不同的内存局部性和不同的复制约束数量。EZKL 内部会做转换，但这层转换本身也要占行。

实践中你不需要手动管，但看到「同样的模型，导出格式不同，行数差 5%」时，别惊讶。

## 六、自检答案

> 问：给定输入 1×3×224×224 和一个 7×7、stride=2 的卷积，算出输出形状。

答：假设 padding=3（ResNet 的配置），H_out = ⌊(224 + 6 − 7)/2⌋ + 1 = 111 + 1 = 112。所以输出空间尺寸是 112×112。通道数由卷积核个数决定（比如 64），batch 保持 1，最终形状是 [1, 64, 112, 112]。

## 七、一句话记住

**形状决定两件事：能不能乘、要花多少钱。记住 H_out = (H+2p−k)/s + 1。**
