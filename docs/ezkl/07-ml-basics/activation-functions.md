# 激活函数

> **核心** ｜ 前置：07_机器学习预备/01_神经网络就是矩阵乘加

**一句话**：ReLU 是「负数归零」；Sigmoid/Tanh 是把数值压进 0~1 或 −1~1 的 S 形曲线；GELU 是平滑版 ReLU。

**在 EZKL 里的落点**：ReLU 在电路里只花几行；Sigmoid/Tanh/GELU 必须查表（circuit/ops/lookup.rs）。

## 一、为什么需要激活函数

没有它，堆多少层都是线性变换 —— 线性变换的复合还是线性变换，等于一层。

激活函数的作用是**引入非线性**，让网络能拟合复杂函数。

## 二、五种常见激活

| 名字 | 公式 | 形状 | 电路成本 |
|---|---|---|---|
| **ReLU** | max(0, x) | 负数归零 | **最低**（一次比较 + 选择） |
| LeakyReLU | max(αx, x) | 负数留一点 | 低（同 ReLU） |
| **Sigmoid** | 1/(1+e^−x) | S 形，压到 0~1 | 高（查表） |
| **Tanh** | (e^x−e^−x)/(e^x+e^−x) | S 形，压到 −1~1 | 高（查表） |
| **GELU** | x·Φ(x) | 平滑版 ReLU | 高（查表 + 乘法） |

## 三、ReLU 为什么便宜

`max(0, x)` 在电路里可以写成：

> 引入一个比特 b ∈ {0,1}，约束 `b·x = 0` 且 `(1−b)·(x − y) = 0`，即「要么 x=0，要么 y=x」。

两条约束、一个辅助比特。**这是所有激活函数里最便宜的。**

注意一个细节：这里用到了「比较 x 和 0」的语义，而域里没有大小（`01/01/01`）。所以实际实现要先把 x 表示成「符号位 + 绝对值」，或者用范围检查约束 b 的取值。**严格说 ReLU 也不完全免费**，但比查表便宜一个数量级。

## 四、Sigmoid/Tanh/GELU 为什么贵

因为它们都是超越函数，电路里只能查表（`03/03/01`）：

- 一次查表 ≈ 一行约束 + 表本身的开销；
- 表要占一组查找表列，且条目数会把 k 的下界顶上去；
- 每个元素都要查一次。

一个 512×512 的全连接层，就是 26 万次查表。**光激活函数就能吃掉几万行。**

## 五、为什么现代网络还是用 GELU

因为精度。

ReLU 在 Transformer 里表现不如 GELU（梯度更平滑），所以 BERT/GPT 全用 GELU。代价是电路里贵得多。

这是一个典型的**「训练效果 vs 部署成本」**的取舍：

| 场景 | 建议 |
|---|---|
| 只跑推理，成本敏感 | ReLU |
| 复现已有模型 | 原样保留，接受成本 |
| 自己设计模型 | 优先 ReLU，除非精度差很多 |

## 六、一个容易被忽略的点

**激活函数的位置也影响成本。**

- 卷积后接 ReLU：可以融合进卷积的输出约束里，省一次遍历；
- 两个卷积之间接 GELU：必须单独一层，独立占行。

所以「同样的模型，把 GELU 换成 ReLU 再重训」，可能让电路行数降 20% 以上 —— 这是 zkML 里非常实用的优化手段。

## 七、自检答案

> 问：说出哪几个激活函数必须查表、为什么。

答：Sigmoid、Tanh、GELU 必须查表，因为它们都是超越函数（含指数、除式或误差函数），电路里无法用有限次加乘精确表达，只能用预先算好的表做近似。ReLU 和 LeakyReLU 不用查表，它们只是「取较大值」，可以用一个辅助比特加两条约束实现，成本低一个数量级。

## 八、一句话记住

**ReLU 是两条约束，Sigmoid 是一张表。激活函数的选择，直接决定电路胖不胖。**
