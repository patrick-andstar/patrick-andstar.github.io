# 残差连接与ResNet

> **支撑** ｜ 前置：07_机器学习预备/03_卷积与感受野

**一句话**：输出 = 输入 + 变换(输入)。这条「直通线」让很深的网络也能训得动，代价是电路里多一次加法、多一份形状对齐。

**在 EZKL 里的落点**：你的 ResNet50 测速对象就靠它堆到 50 层；每多一个 block 就多一批行。

## 一、问题：深层网络反而更差

2015 年之前，人们发现：网络堆到几十层，训练误差反而上升。

这不是过拟合（训练误差也涨），而是**退化问题**：深层的优化变得更难。

## 二、解法：加一条直通线

> **y = x + F(x)**

- x 是输入（恒等映射）；
- F(x) 是几层卷积学到的「残差」；
- 输出是两者相加。

直觉：与其让网络学「完整的变换」，不如让它学「在输入基础上改多少」。后者容易得多。

如果某一层没用，网络可以把 F(x) 学成 0，等价于跳过 —— **至少不会比浅层更差**。

## 三、Bottleneck：ResNet50 的基本块

ResNet50 的每个 block 是三层的「瓶颈」结构：

```
1×1 卷积（降维：256 → 64）
3×3 卷积（64 → 64）
1×1 卷积（升维：64 → 256）
+ 残差
```

为什么这样设计：

- 3×3 卷积最贵，先用 1×1 把通道降到 1/4，省 4 倍计算；
- 再升回去，保持维度一致才能相加。

**ResNet50 = 1 个 stem + 4 个 stage（3/4/6/3 个 block）+ 分类头**，共 50 层（含全连接）。

## 四、在电路里要付什么代价

| 操作 | 电路成本 |
|---|---|
| 加法（x + F(x)） | 每元素一行，很便宜 |
| 形状对齐 | 免费（只改索引） |
| 1×1 卷积 | 本质是矩阵乘，按通道数算 |
| 3×3 卷积 | 最贵，按 MAC 算 |

**关键**：残差本身几乎不要钱，但**它要求 x 和 F(x) 形状完全一致**。

如果通道数变了（比如 stage 之间），就需要一个 1×1 卷积做投影（projection shortcut）—— 这就不是免费的了。

ResNet50 里有 4 处这种投影（每个 stage 的第一个 block）。

## 五、为什么它对 zkML 是「中性」的

好消息：残差不增加行数（只是一次加法）。
坏消息：它**不允许形状变化**，所以你没法靠它省计算。

对比一下：

| 结构 | 对电路的影响 |
|---|---|
| 残差 | 中性（加一次） |
| 池化 | 偏贵（要比较） |
| 深度可分离卷积 | 便宜（MAC 少） |
| 注意力 | 贵（softmax + 大矩阵） |

所以 ResNet 在 zkML 里算是「结构友好」的 —— 它的成本几乎全在卷积的 MAC 上，没有额外的电路惩罚。

## 六、自检答案

> 问：说清残差连接在电路里要不要额外约束，以及它为什么不改变行数量级。

答：要一条逐元素加法约束（y = x + F(x)），但这是一次加法，成本极低，不改变行数量级。前提是 x 和 F(x) 形状一致；如果通道数变化，需要一个 1×1 卷积做投影，那时才会多出矩阵乘的成本。所以残差本身几乎免费，真正贵的是它包着的那些卷积。

## 七、一句话记住

**残差 = 一条加法直通线。电路里几乎免费，但它锁死了形状，不让你靠它省计算。**
