# KZG多项式承诺

> **核心** ｜ 前置：02_承诺与哈希/02_承诺方案/01_承诺的隐藏与绑定性、01_数学地基/02_群与代数结构/02_双线性配对

**一句话**：用一个 32 字节的 G1 点代表整个多项式；想验「p(z)=v」，只需一次配对校验。

**打个比方**：把一整页纸压成一个指纹大小的封条。想验某一行写的是不是 v，只要把封条和那一行对一下，不用把整页摊开。

**在 EZKL 里的落点**：src/pfsys 的 params/kzg；vk 里存的就是这些点。

## 一、要解决的问题

你有一个多项式 p（在 EZKL 里，它代表整个电路的所有约束），它有上百万个系数。

你想向验证者证明两件事：

1. 这个 p 是「定死」的，我事后不能改（**绑定**）；
2. 它在某个点 z 上的值等于 v，但**我不想把 p 交出去**（**只开一个点**）。

哈希承诺做不到第 2 条（只能全开）。KZG 能做到，而且证明只有几十字节。

## 二、三个式子

**前提**：有一份 SRS，里面是 `G, τG, τ²G, …`（τ 是秘密，已销毁）。

**第一步，承诺**：

> C = p(τ)·G

把多项式的系数当成标量，对 SRS 里的点做线性组合。结果是一个点，33 字节。

**第二步，算商多项式**：

> q(X) = (p(X) − v) / (X − z)

这一步能成立，恰恰是因为 **p(z) = v**。多项式余数定理说：p(X) − v 在 X = z 处为零 ⟺ (X − z) 整除它。所以 q 一定是个多项式（不是分式）。

反过来说：如果 p(z) ≠ v，这个除法就除不尽，q 根本不存在 —— 证明者也就造不出 π。

**第三步，打开证明**：

> π = q(τ)·G

又是一个点，33 字节。**整个证明就是这 33 字节。**

## 三、验证：一次配对

验证者手里有 C、π、z、v，以及 SRS 里的 τG、H（G2 生成元）。

他要确认的是 `p(τ) − v = q(τ)·(τ − z)`。两边各乘 G 再配对（`01/02/02`）：

> e(C − v·G, H) = e(π, τH − zH)

成立就说明 p(z) = v。

**注意验证者做了什么**：算 `C − vG`（一次点加 + 一次标量乘）、算 `τH − zH`（同样），然后两次配对。全是常数时间，与多项式多大无关。

## 四、为什么这样就「绑定」了

攻击者想换一个 p′ 但保持 C 不变，就得让 p′(τ)·G = p(τ)·G，即 (p′ − p)(τ)·G = O。

这要求他知道 τ（因为多项式在随机点相等就意味着恒等，`01/04/03`）。而 τ 已经销毁。

所以：**绑定性的根，是「没人知道 τ」。** 这句话在下一篇会变成整个系统的软肋。

## 五、为什么证明能这么小

因为验证只需要「一次幂」的关系：p(τ) 和 q(τ)·(τ−z)。不需要把 p 的每个系数都送过去。

SRS 里也只用到 τ⁰、τ¹ 这两档（加上 G2 的一档）。剩下的 `τ²G, τ³G, …` 是给**多项式乘法**用的（商多项式 q 的次数比 p 低，但计算它需要高次幂）。

这也解释了 SRS 为什么那么大：**它得覆盖电路里可能出现的最高次数**。`logrows = 16` 就要 2¹⁶ 个点。

## 六、在 EZKL 里

- 承诺和打开都在 `src/pfsys`，走 halo2 的 `multiopen`；
- `vk.key` 里存着验证需要的那些点（包括 G2）；
- `proof.json` 里存着若干个 π（一次证明往往要开多个点，`04/02/02` 讲怎么合并）。

## 七、最常见的三个误解

1. **「KZG 证明我知道这个多项式」** —— 不准确。它证明的是「**承诺所对应的那个**多项式在 z 点等于 v」。绑定由承诺保证，不由证明保证。
2. **「验证者拿到了 p」** —— 没有。他只知道一个点和一次配对的结果。
3. **「证明大小随电路增长」** —— 不。KZG 的证明恒定（几十字节），增长的是**生成证明的时间**和 **SRS 的大小**。

## 八、自检答案

> 问：说清 Commitment 与 Opening 各是什么，并写出验证等式。

答：Commitment 是 `C = p(τ)·G`，用一个 G1 点代表整个多项式；Opening 是针对某个点 z 的证明 `π = q(τ)·G`，其中 `q(X) = (p(X)−v)/(X−z)`。验证等式是 `e(C − v·G, H) = e(π, τH − zH)`，两边配对后比较的是指数上的 `p(τ)−v` 与 `q(τ)(τ−z)`。

## 九、一句话记住

**承诺 = 把整页纸压成一个点；打开 = 用一次配对证明某一行写的是 v。全程不交纸。**
