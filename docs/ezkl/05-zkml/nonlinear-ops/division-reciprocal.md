## 一、为什么不能直接除

电路只有加法和乘法两种门（`03/02/02`）。

要算 `x / y`，你不能写一个「除法门」—— 因为除法不是多项式运算（它是有理函数）。

那怎么办？

## 二、办法一：猜商 + 验算

让证明者提供一个候选商 q，电路验证：

> **q · y + r = x**，且 **0 ≤ r < y**

- 如果 q 猜对，等式成立；
- 如果猜错，等式不成立，约束失败，证明作废。

**安全性**：证明者不能随便填一个 q 蒙混过关，因为约束会当场抓住他。

举个具体例子：x = 7，y = 2。

- 证明者填 q = 3、r = 1；
- 验证：3×2 + 1 = 7 ✓，且 1 < 2 ✓；
- 通过。

如果填 q = 4、r = −1：

- 验证：4×2 + (−1) = 7 ✓（等式成立！）
- 但 r = −1 不满足 `0 ≤ r < y` → 被范围检查抓住。

**注意最后一步**：光有等式不够，必须配 `r` 的范围检查（`05/02/04`）。这是最容易被漏掉的地方。

## 三、办法二：查表求倒数

对「除以一个固定常数」的场景（比如定点乘法的 rescale），可以预先算好 1/y，放进表里：

> 查表得 inv = 1/y，然后验证 `x · inv = 结果`

因为 y 是固定的（比如 2^13），表只有一项，成本极低。

**两种办法的选择**：

| 场景 | 用哪种 |
|---|---|
| 除以变量（LayerNorm 的标准差） | 猜商 + 验算 |
| 除以常数（定点缩放） | 查表 |
| 求倒数（Softmax 的分母） | 查表或猜商 |

## 四、定点乘法里的除法

回忆 `05/02/01`：两个定点数相乘，scale 会叠加，必须除以 2^s。

这个除法在电路里怎么做？

- 因为 2^s 是常数，可以直接查表；
- 或者更省：**右移 s 位**。但域里没有「移位」，所以还是变成「猜商 + 验算」：

> 猜 q，验证 `q · 2^s + r = 乘积`，且 `0 ≤ r < 2^s`

**所以每一次定点乘法，背后都藏着一次除法。** 这是 zkML 成本的重要来源。

## 五、在 EZKL 里

- `LookupOp::Div`：查表除法；
- `src/circuit/ops/hybrid.rs`：混合实现（部分查表、部分算术）；
- `LookupOp::Sqrt`：开方也是同理（猜一个平方根，平方回去验）。

**一个可观察的现象**：模型里如果有很多 LayerNorm，`required_lookups` 里会出现大量 `Div` 和 `Sqrt`，行数也跟着涨。

## 六、自检答案

> 问：说清「为什么 x/y 要写成 x = q·y + r」。

答：因为电路只能做加法和乘法，无法直接表达除法。让证明者提供商 q 和余数 r，电路只验证两条：q·y + r = x（乘法+加法，电路原生支持）和 0 ≤ r < y（范围检查）。若 q 或 r 造假，等式或范围检查必然失败，所以「猜」是安全的。这个技巧叫「用验证代替计算」。

## 七、一句话记住

**电路不会除，只会验。让证明者猜一个商，你用乘法验回去，再用范围检查堵住余数。**
