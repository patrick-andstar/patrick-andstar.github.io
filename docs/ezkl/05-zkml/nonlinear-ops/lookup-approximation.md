# 查表近似

> **核心** ｜ 前置：03_算术化/03_查找表/01_为什么需要查找表

**一句话**：sigmoid / tanh / gelu / exp 全部预计算成表，电路里只做一次成员查询；表的精度就是模型的精度。

**在 EZKL 里的落点**：src/circuit/ops/lookup.rs（Sigmoid/Tanh/Exp/Erf/Gelu 等）。

> 读完约 8 分钟。这一篇把「查表」从一个概念落到具体数字：多少档、多大误差。

## 一、一张表长什么样

以 sigmoid 为例。取值域选 [−8, 8]，因为再往外 σ(x) 基本就是 0 或 1 了。

bits = 8 → 256 档 → 步长 = 16/256 = **0.0625**。

> 说明：这里的 [−8, 8] 与 bits=8 是**举例假设**，目的是把算术走通。EZKL 的实际表范围由 `settings.json` 里的 `scale` 与 `bits` 决定（表覆盖的是定点整数区间），不同模型不一样。下面所有误差数字都按这个假设算，换参数要重算。

表的内容大概是这样：

| 索引（整数） | 输入区间 | 存的 σ 值 |
|---|---|---|
| 0 | [−8.000, −7.938) | 0.000335 |
| 1 | [−7.938, −7.875) | 0.000361 |
| … | … | … |
| 128 | [0.000, 0.063) | 0.500 |
| 255 | [7.938, 8.000] | 0.99966 |

电路里的操作：

1. 把定点输入 x 映射成索引 `i = round((x + 8) / 0.0625)`；
2. 查表得 `y = T[i]`；
3. 证明「(i, y) 这一对确实在表里」。

## 二、误差有多大

sigmoid 的最大导数在 x=0 处，等于 0.25。用区间中点近似，最大误差约：

> 0.25 × 0.0625 / 2 ≈ **0.0078**

也就是千分之八。听起来不大，但要注意：**这是单次误差的上界，不是平均值。**

实际误差分布不均：在 x=0 附近最大（曲线最陡），在两端几乎为零（曲线平坦）。

## 三、误差会怎么传下去

假设一层里有 512 个神经元，每个都用这张表：

- 单点误差 ≤ 0.0078；
- 下一层是加权求和，误差会被权重放大：Σ|wᵢ| × 0.0078；
- 如果权重和是 10，那这一层输出误差就到 0.078。

**逐层放大是常态。** 所以校准要测端到端误差，不是单层误差（`05/02/02`）。

## 四、为什么不能把 bits 调大

可以，但代价是行数：

| bits | 表行数 | 单点误差 | 3 个算子的总行数 |
|---|---|---|---|
| 8 | 256 | 0.0078 | 768 |
| 10 | 1,024 | 0.0020 | 3,072 |
| 12 | 4,096 | 0.0005 | 12,288 |
| 16 | 65,536 | 0.00003 | 196,608（直接顶到 k=18） |

最后一行是分水岭：**三张 16 位的表就比整个小模型还大。**

## 五、EZKL 里的实现细节

- `LookupOp::Sigmoid` 等枚举，每种对应一张表；
- 表的生成是**惰性**的：编译时只算一次，缓存在 `cache` 目录；
- 表内容进 fixed 列 → vk 绑定（所以换表等于换电路）；
- 表范围由 `RANGE_MULTIPLIER = 2` 之类的安全系数决定，避免边界值查不到。

注意最后一条：如果输入超出表的范围（比如 sigmoid 输入 9.0），查表会**失败**，证明不成立。所以电路里通常要先 clamp（把值截断到范围内）—— 而 clamp 本身又是一次范围检查。

## 六、一个容易忽略的细节

查表的输入是**定点整数**，不是浮点。

所以「x = 0.1」先被量化成整数（比如 s=13 时是 819），再映射到索引。**两次离散化叠加**：量化一次，查表再一次。

这意味着误差有两个来源，不能只算查表那一份。实际系统里，查表步长通常选得比量化精度粗，所以查表误差是主导项。

## 七、自检答案

> 问：说清「sigmoid 的表有多大、误差多少」，以及误差怎么传到输出。

答：取域 [−8,8]、bits=8，表有 256 档、步长 0.0625，最大误差约 0.25×0.0625/2 ≈ 0.0078。误差传到输出有两条路径：一是同一层内被后续加权求和放大（误差 × 权重绝对值之和），二是逐层累积，20 层后可能放大到百分之几。所以必须用端到端样本验证，而不能只看单层误差。

## 八、一句话记住

**sigmoid 在电路里就是一张 256 行的表。误差千分之八，逐层放大，靠端到端校准兜住。**
