# 复制约束与置换论证

> **核心** ｜ 前置：03_算术化/02_PLONKish/01_三类列、01_数学地基/04_多项式/03_多项式恒等式与Schwartz-Zippel

**一句话**：同一条「线」上的值必须相等；逐个列等式太多，于是用置换 + grand product 一次性证明全部相等。

**打个比方**：要证明 1000 个格子的值彼此相等，不用写 1000 条等式；只要证明「它们能被重新排成一模一样的序列」。

**在 EZKL 里的落点**：halo2 的 permutation argument。

## 一、问题

上一篇的例子：`t = x·x` 在第 1 行，`y = t + 3` 在第 2 行。

这两行里的 `t` 必须是**同一个值**。否则证明者可以第 1 行填 16、第 2 行填 100，两条约束各自成立，但整个计算是假的。

怎么保证？

**朴素办法**：给每一对「应该相等」的格子写一条等式约束 `cell_i − cell_j = 0`。

问题：一个真实电路有上百万个格子，其中几百万对相等关系。**逐个写，约束数爆炸**，比省下的还多。

## 二、换一个问法

不逐对证明相等，而是：

> 把所有格子的值排成一个序列，然后**按「谁应该等于谁」重新排一次**。如果两次排出来是同一堆值，那就说明相等关系成立。

举个三个格子的例子。假设 A、B、C 三个格子，约定 A 和 C 必须相等：

- 原序列（按位置）：`[A, B, C] = [3, 7, 3]`
- 按「相等关系」重排：把 C 的位置指向 A → `[3, 7, 3]`

两个序列是同一堆值（都是两个 3、一个 7），所以 A = C 成立。

如果有人作弊，把 C 改成 5：

- 原序列 `[3, 7, 5]`
- 重排后 `[3, 7, 5]`（看起来一样）

等等 —— 这里要靠「重排」的定义：σ 把位置 i 映到「和它应该相等的那个位置」。如果 C 应该等于 A，但值是 5，那么 σ 作用后得到的是 `[3, 7, 3]`（因为它去取了 A 的值）。于是两个序列 `[3,7,5]` 和 `[3,7,3]` 不是同一堆值 → 露馅。

**这就是置换论证的核心：让「应该相等」变成「两个序列互为排列」。**

## 三、怎么用「一个连乘」验两堆值是否相同

验两个多重集相等，最土的办法是排序后逐个比。但在电路里排序极贵。

有个更省的办法：**随机挑战 + 连乘**。

给每个值加一个随机数 β，然后连乘：

> ∏ (值ᵢ + β)

如果两堆值完全相同，这两个连乘**必然相等**（顺序无关）。如果不同，随机 β 下相等的概率极低。

于是验证「两堆值相同」变成验证「两个数相等」—— 一个等式搞定。

## 四、grand product：把它做成一行行的

实际实现不是一次算完整个连乘，而是逐行累积：

> **Z(ω·X) · ∏ⱼ ( pⱼ(X) + β·sⱼ(X) + γ ) = Z(X) · ∏ⱼ ( pⱼ(X) + δʲ·X·β + γ )**

- pⱼ 是第 j 列的值，sⱼ 是「它该去的位置」上的值；
- δ 是一个固定的域元素，用来区分「第几列」；
- β、γ 是两个随机挑战：β 防止不同值互相抵消，γ 防止分母为零；
- 从 Z=1 出发，最后要回到 1。

**简化记法**：只想要直觉的话，可以记成 `Z(ωX) = Z(X)·(f+β)/(g+β)`。但真实递推里还有 γ 和 δʲ —— 去掉 γ，分母可能为零；去掉 δ，不同列之间就能互相冒充。这两个不是装饰。

直觉：每一步乘一个比值。如果两堆值相同，分子分母一路抵消，转一圈回到 1；如果不同，最后落到别的值上，回不到 1。

这个 Z 就是所谓的 **grand product**，在电路里占一列，逐行递推。

## 五、为什么这一步是「电路」的关键

因为神经网络里全是「同一个值被多处使用」：

- 一个卷积核的权重，被几千个位置共用；
- 一层的输出，是下一层的输入；
- 残差连接的直通线。

没有复制约束，你没法表达「这是同一个张量」，整个模型就散成一堆互不相关的数。

## 六、在 EZKL 里

- halo2 的 `permutation` 参数负责这套论证；
- EZKL 在 `src/circuit/region.rs` 里给每个张量分配「列 + 行区间」，同一张量在不同算子间复用时，靠复制约束绑定；
- 这也是为什么「张量形状」会影响行数：形状决定它要占多少格子，以及要建多少条相等关系。

## 七、自检答案

> 问：说清「为什么不能把每个相等关系都写成一条约束」。

答：因为相等关系数量与电路规模同阶甚至更多（一个权重被几千处复用就是几千条）。每条约束都要占行、进商多项式，成本线性叠加，会把本来能装下的电路撑爆。置换论证把「N 条相等关系」压成「一个连乘等式」，只占一列、逐行递推，成本从 O(N) 条约束降到 O(N) 行但只有常数条约束。

## 八、一句话记住

**不逐个证明「这两个相等」，而是证明「这两堆值互为排列」。一个连乘，抵一万条等式。**
