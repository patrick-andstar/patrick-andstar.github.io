# 三类列

> **核心** ｜ 前置：03_算术化/01_从计算到约束/01_电路抽象与witness

**一句话**：advice 列放见证、fixed 列放常量、instance 列放公开输入。EZKL 的五种可见性各自落在这几类列上。

**打个比方**：advice 是你自己填的草稿列，fixed 是印死在纸上的表格列，instance 是最后交给老师看的答案列。

**在 EZKL 里的落点**：circuit/region.rs 的 columns；graph/vars.rs 的 Visibility。

## 一、先把表格画出来

PLONKish 的电路不是「门和线」，而是一张**表格**：

| 行 | advice 0 | advice 1 | fixed 0 | instance 0 |
|---|---|---|---|---|
| 0 | x | t | 1 | — |
| 1 | t | y | 3 | — |

- 每一行是「一个运算时刻」；
- 每一列是一类数据。

只有三类列：

| 列类型 | 谁写 | 能不能变 | 验证者看得见吗 |
|---|---|---|---|
| **advice** | 证明者（生成 witness 时填） | 每次证明都不同 | 看不见（被承诺藏住） |
| **fixed** | 电路设计者（compile 时写死） | 编译后永远不变 | 间接可见（vk 绑定） |
| **instance** | 公开输入 | 每次不同 | **直接看得见** |

## 二、三类的分工，一句话记住

- **advice = 草稿纸**：这次计算的具体数字；
- **fixed = 印好的表格**：常量、选择子、查找表内容；
- **instance = 交上去的答案**：验证者要直接读的那几个数。

## 三、为什么要分这么细

因为**「变不变」决定了「能不能预先算」**。

fixed 列的值在 compile 时就固定了，所以：

- 验证者可以事先把它们算进 vk；
- 证明者不用每次重发；
- 但**改一个值就得重新 compile + setup**。

advice 列每证明一次填一次，所以灵活，但**必须被承诺**（否则证明者可以事后改）。

instance 列不承诺，直接明文放进 proof —— 所以它必须小，而且必须真的是「可以公开」的东西。

## 四、这套分类对应 EZKL 的五种可见性

`src/graph/vars.rs` 里的 `Visibility` 枚举（**五种，不是三种**）：

| 可见性 | 落到哪 | 后果 |
|---|---|---|
| `private` | advice | 只进 witness，vk 不管它 |
| `public` | instance | 明文进 proof，谁都能看 |
| `fixed` | fixed | 焊进电路，vk 绑定 |
| `hashed` | advice + Poseidon 哈希 | 不公开原文，但绑定其哈希 |
| `polycommit`（枚举名 `KZGCommit`） | KZG 承诺点 | 用曲线点绑定，不是哈希 |

这就是为什么 `--param-visibility fixed` 能让 vk 绑死权重：**权重被写进了 fixed 列**（`04/03/05`）。

## 五、代价：fixed 是「焊死」

把 25 M 个参数的权重写进 fixed 列，意味着：

1. `vk` 里要包含对这些常量的承诺 → vk 变大；
2. 换一版权重 → 电路变了 → 必须重跑 `compile` + `setup` + 重新生成 `pk`（本项目 265 MB，重跑要几秒到几分钟）；
3. 联邦学习每轮都换权重 → 每轮都要重新 setup，完全不可行。

所以真实系统里通常是：

- **模型结构**（层数、算子）进电路；
- **权重**走 `private` + 一个 Poseidon 承诺（把承诺作为公开输入），这样 vk 只绑结构，权重可以换但承诺必须对。

这是一个典型的「用一层承诺换掉重建电路」的工程折中。

## 六、一个容易忽略的点

instance 列是**明文**的。

这意味着：你放进 instance 的东西，验证者（以及任何拿到 proof 的人）都能直接读。所以「公开输入」这个词是有代价的 —— 它不是「公开给验证者」，是「公开给全世界」。

如果你的输入是隐私数据，就必须走 `private` 或 `hashed`（`05/04/02`）。

## 七、自检答案

> 问：说清「把权重写进 fixed 列」意味着什么代价。

答：fixed 列在 compile 时写死，之后不能变。所以权重进 fixed 意味着：vk 会绑定这版权重；换权重必须重新 compile 和 setup（重生成 265 MB 的 pk）；联邦学习每轮换模型的场景直接不可用。换来的是「模型文件完整性」——验证者能确认推理用的就是你声称的那一版权重。

## 八、一句话记住

**advice 是草稿、fixed 是印好的表、instance 是公开的答案。放哪一列，等于选择「灵活性」还是「绑定」。**
