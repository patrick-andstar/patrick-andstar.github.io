## 每题的组织格式

1. **题意** —— 用自己的话说一遍，特别是输入输出边界。
2. **数据量** —— 先看 n 的范围，反推允许的复杂度（这一步决定算法，不是反过来）。
3. **思路** —— 写推导过程：一开始怎么想 → 为什么不行 → 所以改成什么。
4. **代码** —— 可直接编译运行，关键行带注释。
5. **复杂度** —— 时间与空间，以及常数上的坑。
6. **易错点** —— 数组开不开、边界、int 溢出、清空多组数据。

> 核心是**从数据量反推算法**，并保留推导过程，而不是只给结论。
