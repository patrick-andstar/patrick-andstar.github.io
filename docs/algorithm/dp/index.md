## 01 背包：为什么必须逆序

一维写法里，容量那一层倒着扫还是正着扫，是初学最容易错的地方。差别用例子最直观 ——
物品 `(w,v)` 为 `(1,15) (3,20) (4,30)`，背包容量 4：

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    vector<int> w = {1, 3, 4}, v = {15, 20, 30};
    int n = w.size(), C = 4;

    // 逆序：每件物品只用一次 —— 正确
    vector<int> ok(C + 1, 0);
    for (int i = 0; i < n; i++)
        for (int c = C; c >= w[i]; c--)
            ok[c] = max(ok[c], ok[c - w[i]] + v[i]);

    // 正序：同一件物品会被反复取，等于变成了完全背包 —— 错误
    vector<int> bad(C + 1, 0);
    for (int i = 0; i < n; i++)
        for (int c = w[i]; c <= C; c++)
            bad[c] = max(bad[c], bad[c - w[i]] + v[i]);

    cout << "逆序（正确）: " << ok[C]  << "\n";
    cout << "正序（错误）: " << bad[C] << "\n";
    return 0;
}
```

正确答案是 **35**（取 `(1,15)` 与 `(3,20)`）。正序会算出 60，因为它把重量 1 的物品连着取了四次。

**原因**：一维数组压掉了「前 i 件物品」这一维，`c` 的扫描顺序决定了 `dp[c - w[i]]` 读到的是
「还没放第 i 件」的旧值还是「已经放过第 i 件」的新值。逆序保证读到旧值，所以每件只用一次；
正序读到刚更新的值，就等于允许重复取。

## 状态定义要问的两个问题

写转移前先回答清楚，剩下的基本是机械推：

1. **`dp[...]` 的下标代表什么？** 是「恰好」还是「至多」？边界要不要初始化成 `-inf`？
2. **阶段是什么？** 按物品还是按容量？谁在外层循环，决定了能不能用滚动数组。

例如「至多容量」与「恰好容量」的差别：前者 `dp` 全初始化为 0 即可；后者只有 `dp[0] = 0`，
其余置 `-inf`，否则会把「装不满」当成合法方案。

同样的套路在 Python 里对照一遍：

```python
w = [1, 3, 4]
v = [15, 20, 30]
C = 4

ok = [0] * (C + 1)
for i in range(len(w)):
    for c in range(C, w[i] - 1, -1):      # 逆序
        ok[c] = max(ok[c], ok[c - w[i]] + v[i])

print("逆序（正确）:", ok[C])
```
