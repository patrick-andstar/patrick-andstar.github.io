## 笔记怎么写

- **来源可追溯**：页码 / URL / 命令输出，挂不上的显式标「未核实」。
- **软肋主动说**：数据源要 key、没有开源、数字是作者自报 —— 宁可先讲出来。
- **区分「论文说了什么」与「我认为它怎么样」**：两者分节写，不混在一起。
